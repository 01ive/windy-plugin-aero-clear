# Local Development

Follow these steps to debug the plugin locally:

1. Refer to the [Windy plugin debugging guide](https://docs.windy-plugins.com/getting-started/debugging.html).
2. In the project directory, run `npm start` to start the local server.
3. Open [Windy Developer](https://www.windy.com/dev) in your browser.

> **Note:** Accept the browser's security exception when prompted.
